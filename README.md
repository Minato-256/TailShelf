# TailShelf

Tailscaleでつないだ Windows と Mac の間で、デスクトップの表示・操作と、ファイルの共有ができるアプリです。スマホのブラウザからPCを操作することもできます（初期設定はオフ）。Windows同士、Mac同士、WindowsからMac、MacからWindowsの、どの組み合わせにも対応します。

通信経路は Tailscale です。画面・入力・クリップボード・ファイルは端末自身の Tailscale IP と TCP `47621` を使い、同じTailscaleアカウント・登録済み端末・登録で作った鍵を確認してから受け付けます。独自のデスクトップ共有プロトコルを使用しており、Microsoft RDPクライアントとの接続互換性はありません。

## ダウンロード

[GitHub Releases](https://github.com/Minato-256/TailShelf/releases) の最新版から、使うOSのファイルを選びます。

| 対象 | ファイル |
| --- | --- |
| macOS 13以降・Appleシリコン | `TailShelf-1.0.0-arm64.dmg` |
| Windows・x64 | `TailShelf-1.0.0-windows-x64.exe`（ポータブル版。インストール不要） |

Mac版はDeveloper ID署名・公証なし、Windows版はコード署名なしです。初回の起動でOSの警告が出たら、内容を確認したうえで、起動を許可してください。`SHA256SUMS.txt` で、ダウンロードしたファイルを照合できます。

## 使い方

1. 両方の端末で Tailscale を起動し、同じアカウントに接続します。
2. 両方で TailShelf を起動します。
3. 操作される側で、「接続と招待コード」からコードをコピーします。操作する側で、一覧の「未登録」のPCを選び、「端末を登録」でコードを入力します。
4. 操作される側の「リモートデスクトップ」で「画面共有を有効にする」を押します。
5. 遠隔操作も必要なら、共有を有効にした後に「マウス・キーボード操作も許可」をチェックします。初期状態は画面閲覧のみです。
6. 操作する側で接続先を選び「接続する」を押します。表示されたデスクトップをクリックするとキーボード入力が相手に届きます。

共有の有効化・操作許可はアプリ終了時にリセットされます。共有設定の変更、「共有を停止」、アプリ終了、招待コードの再発行は進行中のデスクトップ接続を失効させます。一台のホストに同時に接続できる相手は一台です。

端末一覧は5秒ごととウィンドウへ戻ったときに更新します。「端末を更新」で手動確認もできます。Tailscaleが接続中でも相手のTailShelfへ届かない場合は「アプリ応答待ち」と表示します。登録失敗は登録画面内に理由を表示し、登録中は送信を無効にします。登録済みのPCで認証が失効した場合は「再登録する」で新しいコードを入力してください。

### Macの権限

操作されるMacでは「システム設定 → プライバシーとセキュリティ」で TailShelf の **画面収録** と **アクセシビリティ** を許可してください。開発起動では Electron と表示される場合があります。アプリ内の「Macの権限設定を開く」から要求できます。OSから再起動を求められた場合はアプリを再起動し、共有を再度有効にします。OSが入力ヘルパー自体の許可を要求した場合は、アプリ内の `Contents/Resources/native/input-macos` も許可対象に追加します。

画面収録だけを許可したMacへは閲覧モードで接続できます。マウスとキーボード操作は、OSの許可とホスト側の操作許可がそろってから利用できます。

### 接続中の操作

- マウスの移動、左右・中クリック、ドラッグ、ダブルクリック、縦横スクロールを送信します。
- 「日本語・文字入力」は初期状態でオンです。相手の画面をクリックし、手元のIMEで日本語を変換・確定できます。未確定文字は画面内に表示し、確定文字だけを相手へ送ります。相手側のIMEは英数・直接入力にすると二重変換を避けられます。
- 矢印、Tab、Enter、F1〜F12、テンキー、JISの円記号・ろキーなどは物理キーとして送信します。「日本語・文字入力」をオフにすると文字キーも相手のOS・キーボード配列に従います。
- 「ショートカットを相手OSに合わせる」は初期状態でオンです。MacからWindowsではCommandをCtrlに、WindowsからMacではCtrlをCommandに変換します。専用ソフトなどで元の修飾キーが必要ならオフにできます。
- テキストのクリップボードは約0.9秒間隔で双方向に同期します。接続直後は双方の現在値を基準として記録し、既存の内容を勝手に上書きしません。同時更新は手元側を優先します。Ctrl/Cmd+Vは手元の内容を相手へ送った後で貼り付けキーを送ります。
- **Ctrl + Alt + Shift + Q** で操作モードを解除できます。フォーカスを外したとき、ファイル操作へ移ったとき、切断時にも押下中のキー・マウスボタンを解放します。
- モニター選択、画質変更、全画面、画面に合わせる表示・受信画像の等倍表示、閲覧モードを選べます。全画面でもファイルパネルを表示できます。
- ツールバーの「ファイルを開く」で、画面の隣にこのPCと相手PCのファイルパネルを表示します。「ファイルを参照」への切替でも接続を維持します。画面が非表示の間は画面の取得頻度を下げます。
- 「文字の手動送信・クリップボード」を開くと、手動送受信と文字送信の補助操作を使えます。クリップボードはテキストのみ、一回64K文字までです。画像やFinder/Explorerのファイルクリップボードは未対応です。これらの非テキスト内容がある間は自動同期を止め、その内容を保持します。

### ファイル操作

- ファイルをダブルクリックまたはEnterで開きます。このPCのファイルは手元で、相手PCのファイルは相手側の既定アプリで開きます。相手側で開くには操作を許可されたデスクトップ接続が必要です。
- コピー、同一PC内の切り取り・移動、貼り付け、名前変更、フォルダ作成、ゴミ箱への移動、両方向へのファイル・フォルダ転送を使えます。ゴミ箱は操作するファイルがあるPC側です。
- Ctrl/Cmd+A、C、X、V、F2、Deleteに対応します。Shiftで範囲選択、Ctrl/Cmdで複数選択できます。ファイル操作にフォーカスがある間はアプリメニューのコピーなどよりファイル操作を優先し、入力欄では通常の文字編集を維持します。
- パネル間のドラッグで転送、同じ側のフォルダへのドラッグで移動、Finder/Explorerからドロップしてコピー・転送できます。転送元ファイルはそのまま残ります。
- 同名ファイルは初期状態で「別名で両方残す」です。「スキップ」「置き換える」「停止する」も選べます。置き換えは確認画面を表示します。同名フォルダは停止設定以外では既存フォルダへ合流し、内部のファイルに選択した同名処理を適用します。
- 同一PC内のコピーで同じ名前があると「名前 (1).拡張子」のように別名を付けます。同一PC内の移動・名前変更では同名を上書きしません。
- 転送中は中止できます。中止された未完了ファイルの一時データを削除し、置換予定だった既存ファイルを残します。完了済みのファイルや作成済みフォルダは残ります。転送は一回につき一件のジョブです。
- パス欄はWindowsの `C:\Users\name`、UNCの `\\server\share`、Macの `/Users/name`、`~/Documents`、相対パスを受け付けます。
- 端末間の切り取り移動は未対応です。コピーで転送後、元ファイルを必要に応じてゴミ箱へ移動してください。シンボリックリンクは同一PC内のコピー対象にはできますが、端末間の転送は明示的に拒否します。

## スマホから使う

スマホのブラウザ（iPhoneのSafari、AndroidのChrome）から、PCの画面とファイルを操作できます。スマホにもTailscaleを入れ、同じtailnetに参加させてください。**初期設定はオフ**で、PC側の設定で有効にしたときだけ待ち受けます。

1. 入口にするPCで、設定の「スマホ向けWeb操作」を開き、「Web入口を有効にする」をオンにします。公開先URLと、許可するTailscaleアカウントを入力します（「Tailscaleから自動入力」が使えます）。
2. 画面の案内にあるTailscale Serveのコマンドを、ターミナルで一度実行して、公開URLを用意します。アプリはServeの設定を変更しません。
3. 「接続を確認」で、スマホ用URLからこのPCに届くかを確かめます。
4. 画面の閲覧、操作、ファイル操作は、別々のスイッチで許可します。初期設定はすべてオフです。
5. スマホで「スマホ用URL」を開き、PCに表示した登録コードを入力して、PC側で承認します。

許可したTailscaleアカウントの確認と、承認した登録の両方がそろわないと、PCの一覧も画面も受け取れません。

スマホの最初の画面は「接続先」の一覧です。入口にするPCを複数保存して、切り替えて使えます。登録は接続先ごとに必要です。別の接続先を開くと、保存した一覧が移動先にも届き、まだ持っていない接続先だけを、確認してから追加できます。入口のPCから、他のPCを選んで操作することもできます。

## 通信と制約

画面は一度開始したMediaStreamから継続してJPEGへ変換し、最新の一枚を認証付きHTTPで送ります。遅い接続に古いフレームを積み上げません。最大30fpsを目標とし、回線・画質・CPU・OSの取得速度で低下します。Tailscaleが通信の暗号化を担当します。初期の「自動調整」は画面の応答時間に合わせて取得の間隔を広げ、遅い応答が続けば速度優先へ切り替えます。十分速い状態が続くとバランスへ戻します。「速度優先」「バランス」「高画質」の手動選択は維持し、取得間隔だけ通信状態に合わせます。音声、動画向けの高速ストリーミング、HDR、リモートカーソル形状の同期は実装していません。

ログイン済みのデスクトップを共有します。RDPのような別ユーザーセッションの生成、ロック画面へのログイン、Ctrl+Alt+Delete、UACのセキュアデスクトップ、再起動後の自動再接続、無人での常駐サービスは対象外です。WindowsはOSの入力制限に従い、通常権限のアプリから管理者権限のウィンドウへ操作できません。OSが予約しているショートカットはローカルで処理される場合があります。企業のPowerShell実行制限下では入力ヘルパーが起動できない場合があります。 Windowsで管理者の確認（UAC）やロック画面が出ているときは、遠隔から操作できないため、その旨を画面に表示して入力を止め、その画面が終わると自動で操作を再開します。承認や拒否は、PCの前で行います（TailShelfからは押せません）。

デスクトップ共有に対応するため、旧版のウィンドウ画面キャプチャ保護は外しています。

## ファイル共有

ファイル転送はファイル単位で行います。Windowsの禁止文字・予約名はWindows側で検査します。OS固有の所有者・ACL・拡張属性・代替データストリーム・実行属性や元の日時の完全保存、オフライン転送は未対応です。WindowsとMacで大文字小文字の扱い、禁止名、ゴミ箱対応、使用中のファイルのロックなどが異なる場合は、相手OS側の制約が適用されます。

招待コードと登録で作った鍵はOSの暗号化ストレージで保存します。ファイル本体は保存先へストリームで直接書き込み、同じフォルダ内の一時ファイルから確定します。既存ファイルの置換は完了後のrenameで行います。上書きしない保存はハードリンクを優先し、非対応のディスクでは排他的コピーへ切り替えます。外部フォント、分析、クラウド保管先への通信はありません。Tailscale自体が利用する接続制御・中継サービスはTailscaleの設定に従います。
